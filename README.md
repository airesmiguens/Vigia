# Vigia

A fuel-network intelligence dashboard prototype for Angola's downstream distributors.

Combines real, sourced market data (distributor market share, refining/import context) with a
simulated live station-monitoring engine — tank levels, draw-down rates, stockout risk, and a
priority resupply queue — filterable by province and município.

Built as a proof-of-capability piece to open partnership conversations with fuel distributors
(Sonangol Distribuidora, Pumangol, Sonangalp, Tomsa) around real tank telemetry access.

## Status

Prototype / demonstration build. Station-level data in the live network view is synthetic —
see the in-app disclosure for what's real vs. simulated.

## Run locally

Open `index.html` in a browser — no build step, no dependencies.
